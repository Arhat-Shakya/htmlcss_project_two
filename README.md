# CodeFlow | SaaS Landing Page

A modern, responsive landing page for **CodeFlow**, a fictional cloud-based code editor and developer platform. Built using HTML5 and CSS3, featuring a sleek dark interface, purple accents, and a developer-focused design.

## 🌐 Overview

CodeFlow is designed to represent a next-generation development platform that helps developers write, collaborate, and deploy code efficiently.

This project focuses on creating a visually appealing SaaS website with clean layouts, consistent styling, and responsive design.

## ✨ Features

- **Hero Section** – Eye-catching introduction with a prominent call to action.
- **Services Section** – Showcases the core services offered by CodeFlow.
- **Features Section** – Highlights the platform's key capabilities.
- **Dashboard Showcase** – Visual preview of the developer workspace.
- **Pricing Section** – Three pricing plans: Starter, Pro, and Team.
- **About Section** – Introduces CodeFlow's mission and values.
- **Footer** – Organized navigation links, company information, and social links.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts (Inter)

## 🎨 Design

The website follows a modern dark-themed design system.
